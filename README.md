# 🌐 Kurumsal Web Sitesi Projesi

Bu proje, bir kurumsal şirket için modern, kullanıcı dostu ve responsive (mobil uyumlu) bir web sitesi olarak tasarlanmıştır. Geliştirme süreci boyunca kullanıcı deneyimi, performans ve temiz kod yapısı ön planda tutulmuştur.

## 📌 Proje Özeti

- 🔧 Geliştirme Süresi: Yaklaşık 1 ay
- 🏢 Proje Türü: Kurumsal Web Sitesi
- 💼 Amaç: Kurumsal kimliği dijital ortama taşımak ve profesyonel bir çevrim içi varlık oluşturmak


## 🔐 Yorum Sistemi 
📝 Kullanıcılar, blog gönderilerine yorum yapabilir.

📌 Yorumlar, ilgili blog ID’siyle eşleştirilerek veritabanına kaydedilir.

🔒 Varsayılan olarak yorumlar pasif durumda saklanır.

✅ Admin panelinden onaylanan yorumlar, eşleşen blog gönderisine dinamik şekilde yansıtılır.

🔄 Bu yapı sayesinde içerik-güncelleme senkronizasyonu sağlanmış olur ve kullanıcı deneyimi artar.




## 🎯 Proje Özellikleri

- Ana sayfa, hizmetler, hakkımızda, iletişim gibi temel kurumsal sayfalar
- Modern ve sade kullanıcı arayüzü
- Tüm cihazlarla uyumlu responsive tasarım
- Temiz ve anlaşılır kod yapısı
- Sayfa yapısı, başlık etiketleri ve meta veriler SEO uyumlu olacak şekilde yapılandırılmıştır.
- Gerektiğinde kolayca ölçeklenebilir altyapı
